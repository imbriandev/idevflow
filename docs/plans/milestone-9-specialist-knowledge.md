# Milestone 9 — Specialist Knowledge Parity

## Purpose

v1.0.0 proved deterministic workflow safety, but its stage skills lacked the legacy workflow’s broad iOS specialist cold path. This milestone closes that quality gap without reintroducing AppForge Python runtime, unbounded prompt loading, or prose authority over the kernel.

## Pi-native knowledge layer

`pi_ios_context` is a typed read-only selector. Given lifecycle stage, risk, task, and optional surfaces, it detects domain terms and returns at most four readable package-owned references under a deterministic budget:

- 2,400 estimated tokens for normal work;
- 3,200 for critical/release work;
- stage defaults first, then required release/privacy/testing references, then directly matched surfaces.

It returns an absolute package path plus relative audit path, reason, selected/deferred references, estimated budget, and detected surfaces. It does not read project source or grant authority. Milestone 10 adds an atomic session-bound context receipt for high-risk/release enforcement. Workers receive this tool in their restricted allowlist and must select context before loading specialist material.

## Ported expert reasoning

The curated cold path covers product/SLC and interface language, SwiftUI experience, SwiftData/CloudKit/concurrency, testing and evidence, privacy/security, StoreKit/RevenueCat, review/audit, release/TestFlight, and App Intents/WidgetKit/legacy platform boundaries.

Each reference has practical checks, evidence expectations, and explicit limits. High-risk privacy/persistence/release reasoning is now available in the same package as the deterministic gate that enforces it. `references/legacy-coverage.md` maps all 44 AppForge references to a ported reference, a stronger TypeScript kernel behavior, or an explicit omission for Python/remote/manual operations.

## Skill behavior

Every lifecycle skill now tells the agent when to call `pi_ios_context` and how to convert loaded guidance into acceptance criteria, tests, evidence, or evidence-linked findings. Skills prohibit checklist-only claims. The active-stage injection repeats the bounded selector rule for normal prompts; worker prompts repeat it in isolated pipeline execution.

## Proof

`tests/knowledge-context.test.ts` validates:

- high-risk SwiftData/concurrency selection and package-readable paths;
- critical TestFlight/StoreKit/accessibility selection without unrelated preloading;
- all seven skills calling the selector;
- every manifest reference existing;
- all 44 legacy references accounted for.

`tests/expert-reasoning-evals.test.ts` exercises expert scenarios for SwiftUI accessibility, SwiftData migration/actors, permission/sensitive-data review, StoreKit restore, and WidgetKit/App Intents. Tests enforce a maximum of four references and the declared budget. Worker-launch tests ensure isolated workers receive the context selector and procedure.

## Result

Specialist reasoning is no longer a deferred parity item. Pi iOS retains the stronger deterministic safety model while supplying a bounded, auditable knowledge base for product-quality iOS work.
